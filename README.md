# A100 — Official Artist Website

Official artist website for **A100**, built from the approved master October artist website template.

## Features
- **Hero Background & Visuals**: High-performance hero media and sharp poster frame extracted from A100's official visuals.
- **Discography & Stream Modal**: Direct multi-platform streaming links (Spotify, Apple Music, YouTube Music, Deezer, Amazon Music, Tidal, iTunes) for 5 featured releases:
  - *Impatient Perfectionist* (Album / EP, Aug 6, 2026)
  - *Fire In The Streets* (Single, Jun 4, 2026)
  - *Bond* (Single, Apr 9, 2026)
  - *In Da Club* (Single, Jul 2, 2024)
  - *Shottas (feat. Recky Rondo)* (Single, Feb 20, 2026)
- **Videos Section & Featured Visuals**: Official YouTube videos:
  - *A100 - Impatient Perfectionist The Ep [TRAILER]*
  - *A100 - BOND [music video]*
  - *A100 x Recky Rondo - Shottas*
- **Socials & Streaming Bar**: Verified icons and direct links for Spotify, Apple Music, YouTube, Instagram, and TikTok.

## Development & Deployment
```bash
# Install dependencies
npm install

# Run locally
npm run dev

# Type check
npm run lint

# Build for production
npm run build

# Deploy to Cloudflare
npx wrangler deploy
```
